# LMM CI: LMM Chat Interface

> A Yew CSR chat interface demonstrating the **LMM** (Large Mathematical Model) framework for deterministic and stochastic text generation using the TRAM pipeline.

## Running

```bash
cd chat
trunk serve --port 3000
# Open http://localhost:3000
```

## Building for Production

```bash
trunk build
# Output in dist/
```
